Hear your order email the way a screen reader does.

Readable is four Hyper Elements email templates that pass WCAG 2.2 AA, for the European Accessibility Act, and a plugin that won't let an email that fails be sent.

Below is a typical order confirmation. Press Listen, then switch to Readable. Or check your own email.

    In a template
    
      
    One plugin, required the way lint's own rules are. Every template here requires all {{REQUIRED}} rules, in English, German, French and Arabic.
    
    
    
    
    
      
    
        
    It runs on the laid-out email
    
        
    readable() is a Hyper Elements lint plugin. It reads each element's resolved colours, sizes and padding, and adds {{OWN}} rules to lint's {{LINT}}.
    
        
    It fails closed
    
        
    A template lists the rules it requires. check() fails if one finds something, and if the plugin throws, the rule counts as not run, never as passed.
    
        
    It leaves a record
    
        
    Each template's check() becomes a conformance report, a Hyper Elements Document: what passed, and what a person still confirms.
    
      
    

    import { readable } from "./src/wcag";

export const PasswordReset = template({
  id: "readable.PasswordReset",
  root: "Email",
  fields: { code: prop.text({ pattern: "^[0-9]{6}$" }) },
  rules: {
    plugins: { lint: readable({ kind: "transactional" }) },
    require: {
      lint: ["contrast", "lang", "target-size", "code-readout", /* all {{REQUIRED_LINT}} */],
      core: ["layout/overflow"],
    },
    links: { domains: ["fernhill.example"], schemes: ["mailto"] },
    root: { lang: true, title: true, previewText: true },
  },
  render: (v) => <Text>{group(v.code)}</Text>, // "482 913"
});

PasswordReset.check(values).valid; // false while a required rule fails
