For the European Accessibility Act

Transactional emails everyone can read.

Since June 2025, shops in the EU must send emails people can read with a screen reader, a magnifier or tired eyes. Readable is {{TEMPLATES}} Hyper Elements email templates that work for them, and a WCAG plugin that stops any email that doesn't from being sent.

    How it works
    
    
    Built on Hyper Elements, the way it's meant to be used
    
    
    Three parts, each one a Hyper Elements feature.
    
    
    
      
    
        1
        
    A plugin that templates require
    
        
    readable() runs lint's rules and adds {{OWN}}. A template requires them, so check() fails if one finds something, or doesn't run.
    
      
    
      
    
        2
        
    {{TEMPLATES}} templates that pass all {{REQUIRED}}
    
        
    Typed fields, words in {{LOCALES}} languages, links that can only go to the shop and its carriers. Every rule passes in every language.
    
      
    
      
    
        3
        
    A report for each
    
        
    A Hyper Elements Document that maps check() to WCAG 2.2, and says what a person still confirms.
    
      
    
    
    
    
    
      See the plugin in a template

    // One plugin: lint's {{LINT}} rules, and Readable's {{OWN}}.
import { readable } from "./src/wcag";

export const PasswordReset = template({
  id: "readable.PasswordReset",
  root: "Email",
  fields: { code: prop.text({ pattern: "^[0-9]{6}$" }), /* … */ },
  rules: {
    plugins: { lint: readable({ kind: "transactional" }) },
    require: {
      lint: ["contrast", "link-text", "lang", "target-size", "code-readout", "emoji", /* all {{REQUIRED_LINT}} */],
      core: ["layout/overflow"],
    },
    links: { domains: ["fernhill.example", "*.fernhill.example"], schemes: ["mailto"], tags: "deny" },
    root: { lang: true, title: true, previewText: true },
  },
  render: (v) => /* … */ <Text>{group(v.code)}</Text> /* "482 913" */,
});

PasswordReset.check(values);  // { valid, rules: [{ rule: "code-readout", status: "passed" }, …], snapshots }
